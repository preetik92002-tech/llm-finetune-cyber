Every error I hit while building this project, in the order I met them. Each has an id (E01, E02, ...) that the stage pages and the [journal](journal.md) link to.

Home: [README](../README.md) | Docs index: [docs/README.md](README.md) | Numbers: [metrics.md](metrics.md)

> Update rule: when a new error happens, add a row here and an entry to the journal. Error texts are shortened. For E01 the text is the standard Python and pip message, and the folder path in it varies.
